# Legacy Archive

This directory archives the original static HTML/CSS/JS portfolio files:
- `index.legacy.html`: Original portfolio landing page
- `music-room.html`: Music player experience
- `games.html` & `games.js`: Original arcade mini-games
- `script.js` & `styles.css`: Original scripts and styles

These files are preserved for historical reference and to port game logic / music room content into the new React architecture.
